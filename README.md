# Apex Spec Showcase - Performance & Specification Platform

A dynamic, modern web showcase platform built to present and compare detailed technical specifications, power metrics, and speed ratings of high-performance machines.

---

## 🚀 Key Features

- **Interactive Spec Showcase:** Renders technical specifications dynamically into structured card components.
- **Visual Performance Indicators:** Real-time visual progress bars displaying relative Power (PS) and Top Speed (km/h) benchmarks.
- **Real-Time Search & Filtering:** Filter models instantly by name, engine specification, or category (Superbike, Sports Roadster, Modern Classic).
- **Side-by-Side Comparison Tool:** Select up to 3 vehicles to view a complete breakdown in an interactive comparison table.
- **Custom Vehicle Submission:** Add new models directly through a built-in user form with dynamic grid updates.
- **Detailed Specification Modal:** Pop-up view displaying key technology, torque metrics, and engineering features.
- **Responsive Dark Theme:** Modern UI styled with CSS Grid, Flexbox, and CSS variables for smooth cross-device viewing.

---

## 🛠️ Built With

- **HTML5:** Semantic layout structure and modal markup.
- **CSS3:** Custom CSS variables, Flexbox, CSS Grid layout, linear gradients, and responsive breakpoints.
- **JavaScript (ES6+):** Dynamic DOM manipulation, array filtering, event handling, and data binding.
